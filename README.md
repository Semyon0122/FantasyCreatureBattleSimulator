# Fantasy Creature Battle Simulator

Симулятор сражений фантастических существ на C# (.NET).
Лабораторная работа №3 по объектно-ориентированному программированию (ИТМО).

## Возможности

- Описание существ с характеристиками (здоровье, урон, защита и т. д.)
- Модификаторы и зелья для улучшения характеристик существ
- Реализация столов игроков с существами
- Пошаговая симуляция боя между существами

## Структура проекта

```
src/Lab3/            — исходный код симулятора
tests/Lab3.Tests/    — модульные тесты
```

## Требования

- .NET SDK 10.0

## Сборка и запуск

```bash
dotnet build
dotnet test tests/Lab3.Tests
```
